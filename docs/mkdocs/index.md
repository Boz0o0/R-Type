# R-Type

## Ampersand Engine

R-Type is built on **Ampersand Engine**, our own game engine. It lives in its own repository, and CMake fetches the release set by `AMPERSAND_ENGINE_VERSION` with CPM.

- :material-book-open-variant: [Engine documentation](https://boz0o0.github.io/Ampersand-Engine/)
- :material-github: [Engine source code](https://github.com/Boz0o0/Ampersand-Engine)
